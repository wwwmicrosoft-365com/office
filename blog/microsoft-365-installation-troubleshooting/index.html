Microsoft 365 Installation Troubleshooting: Common Errors and Fixes

Published 27 October 2026

Installation stuck or taking too long

The installer downloads several gigabytes, so a slow connection can make it look frozen. Give it time, and check that your internet connection is stable. If the progress bar has not moved for a long while, restart the computer and run the installer again from office.com/setup or microsoft365.com/setup.

  1. 1Restart the computer and try again.
  2. 2Temporarily disable a VPN or proxy if you use one.
  3. 3Free up disk space — Office needs several gigabytes.
  4. 4Run the installer as an administrator on Windows.

“Something went wrong” errors

Generic error messages during setup are often caused by leftovers from an older Office version. Uninstall any previous Office installation first — on Windows, open the Control Panel, go to Programs, select Uninstall a program, find Office, and choose Uninstall. Restart the computer, then install again.

Office will not activate after install

If the apps install but refuse to activate, the signed-in account usually does not match the account that holds the subscription or product key. Open Word, go to File, then Account, sign out, and sign back in with the account you used at office.com/setup. Our activation guide walks through the whole process.

Remove and reinstall Office

When nothing else helps, a clean reinstall solves most problems. Uninstall Office completely, restart the computer, then sign in at office.com/setup or microsoft365.com/setup and select Install Office again. On a Mac, open the Applications folder, find the Office folder, and run the Office uninstaller tool before reinstalling.

Where to get official help

This site is an independent guide and cannot access your account or license. For account-specific problems — a key that will not redeem, a subscription that does not show up, or billing questions — use the official Microsoft Support site at support.microsoft.com/office, where Microsoft can check your account directly.
